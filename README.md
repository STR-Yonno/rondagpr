# Data Warga

Web App untuk menampilkan dan mengelola informasi data warga di perumahan Green Permata Residence.

## Deskripsi

Aplikasi ini dikembangkan untuk membantu pengelolaan dan penyajian
informasi data warga secara terstruktur melalui aplikasi berbasis web.

## Teknologi

- Google Apps Script
- Google Sheets
- Google Drive
- HTML
- CSS
- JavaScript
- GitHub Pages

## Arsitektur

GitHub Pages digunakan sebagai halaman akses aplikasi, sedangkan
proses aplikasi dijalankan melalui Google Apps Script Web App.

User
  ↓
GitHub Pages
  ↓
Google Apps Script Web App
